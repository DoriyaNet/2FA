PSEUDOCODE / 001

验证码如何出现

每一步都发生在你的设备上，与 Google Authenticator 等应用使用相同的开放标准。

const key = base32Decode(secret)
const counter = floor(Date.now() / 30_000)
const digest = HMAC(key, counter)
const offset = digest[19] & 0x0f
code = truncate(digest, offset) % 10⁶
05 PRIVATE BY DEFAULT

明文，
不该离开
你的设备。

本地模式不设置 Cookie、不接入分析服务。二维码解析和 TOTP 计算全部在浏览器完成。连接 GitHub 时，仅有登录会话 Cookie 与经过加密的保险库密文会经过本站后端。

这属于应用层的客户端加密，不构成可独立验证的零知识证明； 托管站点的前端代码仍由部署者提供。需要更强保证时，请自行部署并审计当前版本。
